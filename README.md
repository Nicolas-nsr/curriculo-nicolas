📚 Sobre o Projeto

O objetivo da atividade foi desenvolver um site pessoal com as seguintes características:
Menu fixo presente em todas as seções
Quatro seções obrigatórias: Sobre Mim, Formação, Portfólio e Contato
Estilo desenvolvido sem uso de frameworks de CSS
JavaScript utilizado apenas para lógica do formulário
Publicação obrigatória no GitHub Pages
Organização clara e separada por pastas
